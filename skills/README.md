# Skills — the router

This folder contains focused instruction files for AI-assisted internship work. Load only the skill relevant to the current task, plus the FlyRank data guide for data work.

| Task | Load this skill | Also load for data work |
|---|---|---|
| Write findings, conclusions, a playbook, or public research claims | `writing-honest-claims/SKILL.md` | `flyrank/flyrank-data/SKILL.md` |
| Understand the FlyRank starter and warehouse data | `flyrank/flyrank-data/SKILL.md` | — |

## Task-specific instructions

- **Writing honest claims:** keep conclusions proportional to the evaluation design; cross-sectional snapshot evidence does not establish causation or future outcomes.
- **FlyRank data:** preserve the dataset's label/leakage rules, interpret zero position as missing, and use pseudonymous IDs for grouping only.

These instructions are adapted from the official FlyRank internship starter repository for use in this working copy.
